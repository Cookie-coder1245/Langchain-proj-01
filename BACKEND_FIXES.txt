WHAT WAS BUILT
---------------
1. Pydantic request/response contract
   - InterviewSetupRequest(role, topic, difficulty)
   - QuestionResponse(role, topic, difficulty, question, expected_points)
   - EvaluateRequest(role, topic, difficulty, question, answer)
   - EvaluationResponse(score, strengths, weaknesses, feedback)
   These map 1:1 to what the frontend sends/expects — no mismatched fields.

2. Question generation chain
   ChatPromptTemplate (system + human messages) piped into
   model.with_structured_output(QuestionOutput). Structured output means
   Gemini is constrained to return {question, expected_points} directly
   as a parsed Pydantic object — no manual JSON parsing, no risk of the
   model wrapping its answer in prose or markdown fences.

3. Evaluation chain (this is where RunnableParallel/RunnableLambda live)
   - score_chain: ChatPromptTemplate -> structured output -> ScoreOutput
     (score, strengths, weaknesses)
   - feedback_chain: ChatPromptTemplate -> structured output ->
     FeedbackOutput (feedback text)
   - RunnableParallel runs both chains concurrently against the same
     question/answer, since they're independent judgments that don't
     need to see each other's output.
   - RunnableLambda(merge_evaluation) takes the dict of both branch
     results and merges them into the single EvaluationResponse the
     frontend expects.

4. FastAPI endpoints
   - GET  /health              — simple liveness check
   - POST /generate-question   — takes InterviewSetupRequest, invokes the
                                  question chain, returns QuestionResponse
   - POST /evaluate             — takes EvaluateRequest, invokes the
                                  evaluation chain, returns EvaluationResponse
   Both endpoints catch any chain/model failure and return a clean 502
   with a human-readable message instead of a raw stack trace.

5. CORS
   Configured with CORSMiddleware in main.py, scoped to
   http://localhost:5173 / http://127.0.0.1:5173 (the Vite dev server) —
   not a wildcard. Add your deployed frontend origin to the allow_origins
   list when you host this for real.

6. Model
   gemini-2.5-flash via langchain-google-genai 4.3.2 (the current
   consolidated google-genai SDK — not the deprecated
   google.generativeai package the old version pulled in).
